# Support

English | [简体中文](SUPPORT.zh-CN.md)

Use [GitHub Issues](https://github.com/cixiangtao/url-join/issues) for reproducible joining, protocol, normalization, type, or query-encoding bugs and focused feature requests. Include the package and Node.js versions, input, expected output, actual output, and a minimal reproduction.

Application routing policy and unrelated URL parsing are outside the package's scope. Report vulnerabilities through [Security](SECURITY.md).
