# Security Policy

English | [简体中文](SECURITY.zh-CN.md)

Report suspected vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/cixiangtao/url-join/security/advisories/new), not a public issue. Include the affected version, impact, minimal reproduction, and known mitigation without credentials or private user data.

Security fixes target the latest published version and are delivered through the Actions-owned npm release path. The project does not promise a fixed response or resolution time.
